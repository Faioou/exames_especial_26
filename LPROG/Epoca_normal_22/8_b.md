# 1. O QUE SIGNIFICA MINIMIZAR UM AUTÓMATO?

Minimizar significa:

> **construir um autómato com menos estados, mas que aceite exatamente as mesmas palavras.**

Para isso procuramos estados que são **equivalentes**.

Dois estados são equivalentes quando:

> **não existe nenhuma continuação da palavra que consiga distinguir os dois.**

Por exemplo, se estando em `S1` e em `S3`, qualquer sequência futura de `0` e `1` leva sempre à aceitação nos dois casos, então não precisamos de ter dois estados diferentes.

Podemos juntá-los.

---

# 2. O AUTÓMATO ORIGINAL

Temos:

| Estado | com `0` vai para | com `1` vai para | Final? |
| ------ | ---------------- | ---------------- | ------ |
| S0     | S1               | S2               | Não    |
| S1     | S1               | S1               | Sim    |
| S2     | S3               | S4               | Não    |
| S3     | S3               | S3               | Sim    |
| S4     | S4               | S4               | Não    |

Estados finais:

```text
S1, S3
```

Estados não finais:

```text
S0, S2, S4
```

---

# 3. PRIMEIRO PASSO: SEPARAR FINAIS DOS NÃO FINAIS

Começamos com dois grupos:

```text
Grupo N = {S0, S2, S4}   não finais

Grupo F = {S1, S3}       finais
```

## Porque fazemos isto?

Porque **um estado final nunca pode ser equivalente a um estado não final**.

Por exemplo:

```text
S1 = final
S0 = não final
```

Imagina que a entrada acaba agora.

Se estivermos em `S1`:

```text
aceita ✅
```

Se estivermos em `S0`:

```text
rejeita ❌
```

Só isto já permite distinguir os dois.

Portanto:

```text
FINAL ≠ NÃO FINAL
```

Nunca os podemos fundir.

Até aqui temos apenas:

```text
{S0,S2,S4}     {S1,S3}
```

Isto chama-se uma **partição**: simplesmente dividimos todos os estados em grupos.

---

# 4. AGORA ANALISAMOS O GRUPO {S0,S2,S4}

A pergunta é:

> Os três estados deste grupo comportam-se realmente da mesma maneira?

Vamos começar por `S0`.

As transições são:

```text
S0 --0--> S1
S0 --1--> S2
```

Agora perguntamos:

### A que GRUPO pertence S1?

`S1` é final:

```text
S1 pertence ao grupo F
```

### A que GRUPO pertence S2?

`S2` não é final:

```text
S2 pertence ao grupo N
```

Então resumimos o comportamento de `S0`:

```text
          com 0    com 1
S0          F         N
```

ou simplesmente:

```text
S0 = (F,N)
```

Isto **não significa uma transição nova**.

Significa apenas:

> com `0`, S0 vai para algum estado do grupo F; com `1`, vai para algum estado do grupo N.

---

# 5. FAZEMOS O MESMO PARA S2

Temos:

```text
S2 --0--> S3
S2 --1--> S4
```

`S3` é final:

```text
S3 ∈ F
```

`S4` não é final:

```text
S4 ∈ N
```

Logo:

```text
S2 = (F,N)
```

Até aqui:

```text
S0 = (F,N)
S2 = (F,N)
```

São iguais.

Por enquanto, **não conseguimos distingui-los**.

Portanto continuam juntos.


## VALE LEMBRAR QUE (N,F) E (F,N) SÃO DIFERENTES 

Não. Nesse caso já seriam diferentes.

Se tivesses:

```text
S0 = (F,N)
S2 = (N,F)
```

isso significa:

```text
S0:
0 -> F
1 -> N
```

e:

```text
S2:
0 -> N
1 -> F
```

Como a ordem do par é fixa:

```text
(primeiro = destino com 0,
 segundo   = destino com 1)
```

então:

```text
(F,N) ≠ (N,F)
```

Logo `S0` e `S2` teriam de ser separados logo nessa ronda.

A ideia é esta:

```text
S0 = (F,N)
S2 = (F,N)
```

✅ iguais, porque com `0` ambos vão para F e com `1` ambos vão para N.

Mas:

```text
S0 = (F,N)
S2 = (N,F)
```

❌ diferentes, porque com `0` um vai para F e o outro vai para N.

Muito importante: `(F,N)` aqui é um **par ordenado**, não é um conjunto. A posição conta.

# 6. AGORA S4

Temos:

```text
S4 --0--> S4
S4 --1--> S4
```

E `S4` pertence ao grupo não final `N`.

Portanto:

```text
com 0 -> N
com 1 -> N
```

Logo:

```text
S4 = (N,N)
```

Agora compara:

```text
S0 = (F,N)
S2 = (F,N)

S4 = (N,N)
```

`S4` comporta-se de maneira diferente.

---

# 7. PORQUE SEPARAMOS S4?

Olha para o que acontece se estivermos em `S0` e aparecer `0`:

```text
S0 --0--> S1
```

`S1` é final.

Portanto, com a continuação:

```text
0
```

partindo de `S0`:

```text
aceitamos ✅
```

Agora partimos de `S4` com exatamente a mesma continuação:

```text
S4 --0--> S4
```

`S4` não é final:

```text
rejeitamos ❌
```

Portanto a palavra `0` consegue distinguir `S0` de `S4`.

Logo:

```text
S0 ≠ S4
```

O mesmo raciocínio permite distinguir `S2` de `S4`.

Por isso o antigo grupo:

```text
{S0,S2,S4}
```

divide-se em:

```text
{S0,S2}

{S4}
```

Os finais continuam:

```text
{S1,S3}
```

Portanto agora temos três grupos:

```text
{S0,S2}

{S4}

{S1,S3}
```

Vamos dar-lhes nomes NOVOS para não criar confusão:

```text
X = {S0,S2}
Y = {S4}
Z = {S1,S3}
```

---

# 8. PORQUE NÃO TERMINAMOS AQUI?

Porque `S0` e `S2` ficaram juntos apenas porque, com a divisão anterior muito grosseira,

```text
F / N
```

eles pareciam iguais:

```text
S0 = (F,N)
S2 = (F,N)
```

Mas entretanto o antigo grupo `N` foi dividido:

```text
N
↓
X = {S0,S2}
Y = {S4}
```

Agora sabemos mais.

Portanto temos de voltar a verificar `S0` e `S2` usando **os novos grupos**.

Este é o coração da minimização:

> **sempre que dividimos um grupo, voltamos a verificar os grupos que ainda têm vários estados.**

---

# 9. SEGUNDA ANÁLISE DE S0 E S2

Agora os grupos são:

```text
X = {S0,S2}
Y = {S4}
Z = {S1,S3}
```

Comecemos por `S0`.

```text
S0 --0--> S1
```

`S1` pertence a:

```text
Z
```

Depois:

```text
S0 --1--> S2
```

`S2` pertence a:

```text
X
```

Portanto:

```text
S0 = (Z,X)
```

---

Agora `S2`:

```text
S2 --0--> S3
```

`S3 ∈ Z`.

Depois:

```text
S2 --1--> S4
```

`S4 ∈ Y`.

Portanto:

```text
S2 = (Z,Y)
```

Agora compara:

```text
S0 = (Z,X)

S2 = (Z,Y)
```

São diferentes.

Logo:

```text
S0 ≠ S2
```

e temos de os separar.

---

# 10. MAS PORQUE É QUE S0 E S2 SÃO REALMENTE DIFERENTES?

Esta parte ajuda muito a perceber o algoritmo.

Com apenas **um símbolo**, eles pareciam iguais.

Por exemplo, com `0`:

```text
S0 --0--> S1 final
S2 --0--> S3 final
```

Ambos aceitam.

Com `1`:

```text
S0 --1--> S2 não final
S2 --1--> S4 não final
```

Ambos rejeitam se a palavra acabar ali.

Por isso, olhando apenas um passo, pareciam iguais.

Mas experimenta a continuação:

```text
10
```

Partindo de `S0`:

```text
S0 --1--> S2
S2 --0--> S3
```

`S3` é final:

```text
aceita ✅
```

Agora partindo de `S2`:

```text
S2 --1--> S4
S4 --0--> S4
```

`S4` não é final:

```text
rejeita ❌
```

Portanto a palavra:

```text
10
```

consegue distingui-los.

Logo:

```text
S0 ≠ S2
```

É por isso que o algoritmo precisou de **uma segunda ronda** para descobrir a diferença.

---

# 11. AGORA OS GRUPOS SÃO

Depois de separar `S0` e `S2`:

```text
{S0}

{S2}

{S4}

{S1,S3}
```

Estados que estão sozinhos já não podem ser divididos mais:

```text
{S0}
{S2}
{S4}
```

Só temos de verificar:

```text
{S1,S3}
```

---

# 12. VERIFICAMOS S1 E S3

Temos:

```text
S1 --0--> S1
S1 --1--> S1
```

E:

```text
S3 --0--> S3
S3 --1--> S3
```

Ambos são finais.

Além disso, com `0` e `1`, ambos permanecem dentro do mesmo grupo:

```text
{S1,S3}
```

Logo:

```text
S1 = (Z,Z)

S3 = (Z,Z)
```

São iguais.

E mesmo que continues:

```text
0
1
00
01
10
11
001101...
```

a partir de `S1` permaneces sempre num estado final.

A partir de `S3` também.

Não existe nenhuma palavra futura capaz de distinguir os dois.

Portanto:

```text
S1 ≡ S3
```

São realmente equivalentes.

---

# 13. QUANDO SABEMOS QUE ACABOU?

Quando fazemos uma ronda completa e **já não conseguimos dividir nenhum grupo**.

Chegámos a:

```text
{S0}

{S2}

{S4}

{S1,S3}
```

O único grupo com dois estados é:

```text
{S1,S3}
```

e verificámos que não pode ser dividido.

Então o processo terminou.

---

# 14. O QUE FAZEMOS COM {S1,S3}?

Como são equivalentes, transformamo-los num único estado.

Podemos chamar-lhe:

```text
S13
```

onde:

```text
S13 = {S1,S3}
```

E como tanto `S1` como `S3` eram finais:

```text
S13 é final
```

---

# 15. CONSTRUIR O AUTÓMATO MINIMIZADO

Agora temos quatro estados:

```text
S0
S2
S4
S13
```

Vamos reconstruir as transições.

### A partir de S0

Originalmente:

```text
S0 --0--> S1
```

Como `S1` agora pertence a `S13`:

```text
S0 --0--> S13
```

E:

```text
S0 --1--> S2
```

mantém-se.

---

### A partir de S2

Originalmente:

```text
S2 --0--> S3
```

Mas `S3` agora é `S13`.

Logo:

```text
S2 --0--> S13
```

E:

```text
S2 --1--> S4
```

---

### A partir de S13

Tanto `S1` como `S3` faziam:

```text
0 -> eles próprios
1 -> eles próprios
```

Portanto:

```text
S13 --0--> S13
S13 --1--> S13
```

---

### A partir de S4

Continua:

```text
S4 --0--> S4
S4 --1--> S4
```

---

# 16. RESULTADO FINAL

| Estado | `0` | `1` |         |
| ------ | --- | --- | ------- |
| → S0   | S13 | S2  | inicial |
| S2     | S13 | S4  |         |
| *S13   | S13 | S13 | final   |
| S4     | S4  | S4  |         |

Portanto:

```text
5 estados originais
        ↓
S1 e S3 são equivalentes
        ↓
fundem-se
        ↓
4 estados
```

# A IDEIA QUE DEBES MESMO GUARDAR

Não tentes decorar simplesmente “faço `(B,A)`”.

Pensa desta maneira:

```text
PASSO 1
Separar finais dos não finais.
Porque um final nunca pode ser equivalente
a um não final.

PASSO 2
Dentro de cada grupo, comparar:
"com cada símbolo, para que GRUPO vou?"

PASSO 3
Se dois estados do mesmo grupo vão
para grupos diferentes, separá-los.

PASSO 4
Como os grupos mudaram, repetir.

PASSO 5
Quando já não for possível separar mais,
os estados que ficaram juntos são equivalentes.

PASSO 6
Fundir esses estados.
```

# MAS MESMO QUE UM ESTADO FINAL SEJA IGUAL A UM ESTADO NÃO FINAL, NÃO SE JUNTAM.

Não. **Um estado final e um estado não final nunca podem ser fundidos**, mesmo que tenham exatamente o mesmo comportamento nas transições.

Por exemplo:

```text
S0 = não final
S1 = final
```

e ambos tenham:

```text
S0 = (X,Y)
S1 = (X,Y)
```

Mesmo assim:

```text
S0 ≠ S1
```

Porque basta considerar a continuação vazia:

```text
ε
```

Se a palavra acabar naquele momento:

```text
em S0 -> rejeita ❌
em S1 -> aceita ✅
```

Logo já existe uma forma de distinguir os dois.

É exatamente por isso que a minimização começa sempre por separar:

```text
F = estados finais
N = estados não finais
```

e **nunca mais mistura estados desses dois grupos**.

Portanto, a regra é:

```text
Para poder fundir dois estados:

1. ambos têm de ser finais
   OU ambos têm de ser não finais

E

2. têm de ter comportamento equivalente
   para todas as entradas futuras
```

Assim, mesmo:

```text
não final S0 -> (X,Y)
final     S1 -> (X,Y)
```

não podem ser fundidos. A diferença “final vs não final” por si só já os distingue.
