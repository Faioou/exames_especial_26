

# Antes de tudo, o que significa descrever formalmente e informalmente 

## 1. Primeiro: o que são `a` e `b`?

Num exercício de linguagens formais, normalmente começa-se por definir um **alfabeto**.

Por exemplo:

```text
Σ = {a,b}
```

Isto quer dizer:

> o alfabeto tem apenas dois símbolos: `a` e `b`.

Portanto:

```text
a = símbolo literal
b = símbolo literal
```

Não são variáveis. São caracteres que podem aparecer nas palavras.

Exemplos de palavras construídas com esse alfabeto:

```text
a
b
ab
ba
aab
abba
bbb
```

---

## 2. O que é `Σ*`?

Se:

```text
Σ = {a,b}
```

então:

```text
Σ*
```

significa:

> todas as palavras possíveis formadas com `a` e `b`, incluindo a palavra vazia `ε`.

Portanto:

```text
Σ* = {ε, a, b, aa, ab, ba, bb, aaa, aab, ...}
```

É um conjunto infinito.

---

## 3. O que é `w`?

Quando escrevemos:

```text
w ∈ Σ*
```

o `w` é uma **variável que representa uma palavra qualquer**.

Por exemplo, `w` pode ser:

```text
ab
```

ou:

```text
aabb
```

ou:

```text
bbb
```

etc.

Portanto:

```text
w = uma palavra qualquer
```

enquanto:

```text
a e b = símbolos concretos do alfabeto
```

Esta diferença é muito importante.

---

## 4. Agora esta forma:

```text
L = { w ∈ Σ* | condição }
```

Lê-se:

> `L` é o conjunto das palavras `w` pertencentes a `Σ*` tais que cumprem uma determinada condição.

O símbolo:

```text
|
```

lê-se:

> “tal que”

Exemplo:

```text
L = { w ∈ {a,b}* | w começa por a }
```

Significa:

> todas as palavras feitas de `a` e `b` que começam por `a`.

Então pertencem:

```text
a
ab
aa
aab
abba
```

Mas não pertencem:

```text
b
ba
bb
ε
```

---

# 5. Agora vamos ao `a^n`

Aqui está uma coisa essencial:

```text
a^n
```

não significa potência matemática como:

```text
2^3 = 8
```

Em linguagens formais:

```text
a^n
```

significa:

> repetir o símbolo `a`, `n` vezes.

Exemplos:

```text
a^0 = ε
a^1 = a
a^2 = aa
a^3 = aaa
a^4 = aaaa
```

Da mesma forma:

```text
b^0 = ε
b^1 = b
b^2 = bb
b^3 = bbb
```

---

# 6. O que é `n`?

Agora sim:

```text
n
```

é uma variável numérica.

Representa uma quantidade:

```text
0, 1, 2, 3, 4, ...
```

Portanto:

```text
a^n
```

quer dizer:

> uma quantidade `n` de símbolos `a`.

---

# 7. Agora podemos entender isto

```text
L = { a^n b^n | n >= 0 } = 
L = { w ∈ {a,b}* | existe n ≥ 0 tal que w = a^n b^n }
```

Vamos desmontar.

Temos:

```text
a^n
```

ou seja:

> `n` símbolos `a`

e depois:

```text
b^n
```

ou seja:

> `n` símbolos `b`

Como usamos **o mesmo `n`**, a quantidade de `a` tem de ser igual à quantidade de `b`.

Agora testamos valores.

Se:

```text
n = 0
```

temos:

```text
a^0 b^0
= ε ε
= ε
```

Se:

```text
n = 1
```

temos:

```text
a^1 b^1
= ab
```

Se:

```text
n = 2
```

temos:

```text
a^2 b^2
= aabb
```

Se:

```text
n = 3
```

temos:

```text
a^3 b^3
= aaabbb
```

Portanto:

```text
L = {ε, ab, aabb, aaabbb, aaaabbbb, ...}
```

A linguagem contém palavras com:

> primeiro `n` símbolos `a`, depois exatamente `n` símbolos `b`.

---

# 8. E se tivermos `a^n b^m`?

Agora temos duas variáveis numéricas diferentes:

```text
n
m
```

Então:

```text
a^n b^m
```

significa:

> `n` símbolos `a`, seguidos de `m` símbolos `b`.

Por exemplo:

```text
n = 2
m = 3
```

dá:

```text
a^2 b^3
=
aabbb
```

Aqui não têm de existir tantos `a` como `b`, porque usamos duas variáveis diferentes.

---

# 9. Exemplo com condições

Imagina:

```text
L = { a^n b^m | n >= 1, m >= 1 }
```

Isto significa:

> uma ou mais letras `a`, seguidas de uma ou mais letras `b`.

Exemplos:

```text
ab
aab
abb
aaab
aabbb
aaaabbbb
```

Não pertencem:

```text
a
b
ba
aba
ε
```

---

## O mais importante para não confundires

Guarda esta tabela:

| Símbolo            | Significado                                  |           |
| ------------------ | -------------------------------------------- | --------- |
| `a`, `b`, `0`, `1` | símbolos concretos do alfabeto               |           |
| `Σ`                | alfabeto                                     |           |
| `Σ*`               | todas as palavras possíveis sobre o alfabeto |           |
| `w`                | uma palavra qualquer                         |           |
| `n`, `m`, `k`      | números/quantidades                          |           |
| `a^n`              | `a` repetido `n` vezes                       |           |
| `b^m`              | `b` repetido `m` vezes                       |           |
| `                  | `                                            | “tal que” |
| `L`                | linguagem, ou seja, conjunto de palavras     |           |

Por exemplo:

```text
L = { a^n b^m | n >= 1 e m >= 1 }
```

lê-se simplesmente:

> `L` é o conjunto das palavras formadas por `n` letras `a`, seguidas de `m` letras `b`, em que existe pelo menos um `a` e pelo menos um `b`.

Esse é o significado completo.
