### 1. Dividir em finais e não finais

O PDF manda começar assim:

**Grupo A — não finais**

```text
A = {S0, S2, S4}
```

**Grupo B — finais**

```text
B = {S1, S3}
```

Não podemos misturar finais e não finais porque uns aceitam a palavra se ela terminar ali e os outros não.

---

### 2. Ver para que grupos vai cada estado do grupo A

Agora não interessa ainda **qual estado concreto** recebe a transição. Interessa **a que grupo pertence esse estado**.

Para `S0`:

```text
0 → S1 → grupo B
1 → S2 → grupo A
```

Portanto:

```text
S0 → (B,A)
```

Para `S2`:

```text
0 → S3 → grupo B
1 → S4 → grupo A
```

Logo:

```text
S2 → (B,A)
```

Para `S4`:

```text
0 → S4 → grupo A
1 → S4 → grupo A
```

Logo:

```text
S4 → (A,A)
```

Temos:

```text
S0  (B,A)
S2  (B,A)
S4  (A,A)
```

O PDF diz para **manter juntos apenas os estados que têm combinações iguais**. 

Portanto:

```text
S0 e S2 ficam juntos
S4 é separado
```

Agora temos:

```text
A = {S0,S2}
B = {S1,S3}
C = {S4}
```

---

### 3. Como os grupos mudaram, repetimos



Antes, os três estavam no mesmo grupo:

```text
A = {S0,S2,S4}
```

Agora comparamos:

```text
S0 → (B,A)
S2 → (B,A)
S4 → (A,A)
```

`S0` e `S2` são iguais:

```text
(B,A) = (B,A)
```

Por isso continuam juntos:

```text
{S0,S2}
```

Mas `S4` é diferente:

```text
(A,A)
```

por isso tem de sair desse grupo e formar um grupo novo sozinho:

```text
{S4}
```

Então renomeamos os grupos:

```text
A = {S0,S2}
B = {S1,S3}
C = {S4}
```

O `B` não mudou porque `S1` e `S3` continuaram equivalentes.

Portanto, pensa assim:

```text
ANTES:
A = {S0,S2,S4}

comparamos o comportamento:

S0 = (B,A)
S2 = (B,A)
S4 = (A,A)

DEPOIS:
os iguais ficam juntos
os diferentes separam-se

A = {S0,S2}
C = {S4}
```

E `B = {S1,S3}` mantém-se como estava.







### Re-analisar os grupos dos estados do grupo A


É exatamente o passo 5 do PDF: se houve alterações e ainda existem grupos com vários estados, voltamos a analisá-los. 

Agora existem três grupos:

```text
A = {S0,S2}
B = {S1,S3}
C = {S4}
```

Analisamos `S0` e `S2`.

`S0`:

```text
0 → S1 → B
1 → S2 → A
```

Logo:

```text
S0 = (B,A)
```

`S2`:

```text
0 → S3 → B
1 → S4 → C
```

Logo:

```text
S2 = (B,C)
```

Agora são diferentes:

```text
S0 = (B,A)
S2 = (B,C)
```

Portanto **não são equivalentes** e têm de ser separados.

---

### 4. Verificar S1 e S3

Ainda temos:

```text
B = {S1,S3}
```

`S1`:

```text
0 → S1 → B
1 → S1 → B
```

Logo:

```text
S1 = (B,B)
```

`S3`:

```text
0 → S3 → B
1 → S3 → B
```

Logo:

```text
S3 = (B,B)
```

São iguais.

Portanto:

```text
S1 ≡ S3
```

Isto significa:

> **S1 e S3 são equivalentes e podem ser fundidos.**

---

### 5. Grupos finais da minimização

Ficámos com:

```text
{S0}
{S2}
{S4}
{S1,S3}
```

Só existe um grupo com mais de um estado:

```text
{S1,S3}
```

Logo só estes dois podem ser juntados.

---

### 6. Aplicar o último passo do PDF

O PDF diz:

> nos grupos com mais de um estado, manter um estado e alterar para ele as transições que iam para os outros estados equivalentes. 

Podemos, por exemplo, **manter S1 e eliminar S3**.

Então esta transição antiga:

```text
S2 --0--> S3
```

passa a:

```text
S2 --0--> S1
```

Porque `S3` foi substituído pelo estado equivalente `S1`.

O autómato minimizado fica:

| Estado | `0` | `1` |
| ------ | --- | --- |
| → S0   | S1  | S2  |
| *S1    | S1  | S1  |
| S2     | S1  | S4  |
| S4     | S4  | S4  |

Portanto, seguindo **exatamente o método do PDF**, o resultado é:

> **S1 e S3 são equivalentes; elimina-se um deles. O AFD passa de 5 para 4 estados.**
