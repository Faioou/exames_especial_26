Para um **AFD**, definir formalmente o autómato significa escrever os seus **5 componentes**:

```text
A = (Q, Σ, δ, q0, F)
```

No autómato que construímos para reconhecer palavras que contêm `00` ou `11`, fica assim.

### 1. Q — conjunto de estados

Temos quatro estados:

```text
Q = {S0, S1, S2, S24}
```

Onde:

```text
S0 = estado inicial, ainda não foi lido nenhum símbolo

S1 = ainda não apareceu 00 nem 11,
     e o último símbolo lido foi 0

S24 = ainda não apareceu 00 nem 11,
     e o último símbolo lido foi 1

S2 = já apareceu 00 ou 11
```

`S2` é o estado final.

### 2. Σ — alfabeto

O enunciado dá:

```text
Σ = {0,1}
```

### 3. q0 — estado inicial

O estado inicial é:

```text
q0 = S0
```

Aqui `q0` é o nome genérico usado na definição formal. No nosso desenho, esse estado chama-se `S0`.

### 4. F — conjunto dos estados finais

Só temos:

```text
F = {S2}
```

Porque `S2` significa:

> já encontrei `00` ou `11`.

### 5. δ — função de transição

`δ` diz:

> estando num determinado estado e lendo `0` ou `1`, para que estado vou?

As transições são:

```text
δ(S0,0) = S1
δ(S0,1) = S24

δ(S1,0) = S2
δ(S1,1) = S24

δ(S24,0) = S1
δ(S24,1) = S2

δ(S2,0) = S2
δ(S2,1) = S2
```

Podes também apresentar `δ` numa tabela:

| Estado | 0  | 1  |
| ------ | -- | -- |
| S0     | S1 | S24 |
| S1     | S2 | S24 |
| S24     | S1 | S2 |
| S2     | S2 | S2 |

Portanto, a definição formal completa é:

```text
A = (Q, Σ, δ, S0, F)
```

onde:

```text
Q = {S0,S1,S2,S24}

Σ = {0,1}

F = {S2}
```

e:

```text
δ(S0,0) = S1
δ(S0,1) = S24
δ(S1,0) = S2
δ(S1,1) = S24
δ(S24,0) = S1
δ(S24,1) = S2
δ(S2,0) = S2
δ(S2,1) = S2
```

A coisa principal para decorar é:

```text
AFD = (Q, Σ, δ, q0, F)

Q  = estados
Σ  = alfabeto
δ  = transições
q0 = estado inicial
F  = estados finais
```
