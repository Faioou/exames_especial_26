
## Como este código nasce do enunciado

O enunciado diz:

> **“criar duas threads geradoras de tráfego [...] e uma thread controladora do semáforo”**

Daí termos:

```c
pthread_create(... gerador_carros ...);
pthread_create(... gerador_peoes ...);
pthread_create(... controlador ...);
```

Isto segue o padrão de criação de threads da T9. 

Depois diz:

> **“Carros e peões bloqueiam de forma passiva até o semáforo estar verde para o seu tipo”**

Por isso os carros fazem:

```c
while (s->verde_para != CARROS ||
       s->passagens == 5) {

    pthread_cond_wait(&s->cond_carros,
                      &s->mutex);
}
```

E os peões fazem o equivalente:

```c
pthread_cond_wait(&s->cond_peoes,
                  &s->mutex);
```

Não existe:

```c
while (...) {
    /* ficar continuamente a verificar */
}
```

Logo não há busy waiting.

Depois o enunciado diz:

> **“Cada passagem demora 1 segundo”**

Daí:

```c
sleep(1);
```

`sleep()` também consta da Reference Sheet. 

A frase:

> **“O semáforo muda de estado [...] após permitir a travessia de 5 entidades”**

é implementada com:

```c
s->passagens++;
```

e quando:

```c
s->passagens == 5
```

fazemos:

```c
pthread_cond_signal(&s->cond_controlador);
```

O controlador acorda e troca:

```c
CARROS → PEOES
```

ou:

```c
PEOES → CARROS
```

## A lógica em português muito simples

Pense no programa assim:

```text
Começa verde para CARROS
          ↓

Carro 1 passa
Carro 2 passa
Carro 3 passa
Carro 4 passa
Carro 5 passa
          ↓

controlador acorda
          ↓

MUDA PARA PEÕES
          ↓

Peão 1 passa
Peão 2 passa
Peão 3 passa
Peão 4 passa
Peão 5 passa
          ↓

controlador acorda
          ↓

MUDA PARA CARROS
          ↓

...
```

Enquanto estiver verde para carros:

```text
CARROS → podem passar
PEÕES  → pthread_cond_wait()
```

Enquanto estiver verde para peões:

```text
PEÕES  → podem passar
CARROS → pthread_cond_wait()
```

E há um detalhe importante no código:

```c
s->passagens == LIMITE_PASSAGENS
```

também impede um **6.º carro** de passar enquanto o controlador ainda não teve oportunidade de mudar o semáforo.

### Quanto à Reference Sheet

As funções de sincronização usadas são todas permitidas:

```c
pthread_create()
pthread_join()

pthread_mutex_init()
pthread_mutex_lock()
pthread_mutex_unlock()
pthread_mutex_destroy()

pthread_cond_init()
pthread_cond_wait()
pthread_cond_signal()
pthread_cond_destroy()

sleep()
```

Todas constam da Reference Sheet. 

A única exceção é `printf()`, que **não está na Reference Sheet**, mas neste exercício o próprio enunciado lhe dá explicitamente autorização para a usar dentro das threads: diz que pode considerar `printf()` segura para este efeito. Portanto aqui é correto utilizá-la.
