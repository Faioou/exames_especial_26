A tabela passou a ser:

| Estado | 0    | 1    |
| ------ | ---- | ---- |
| `S0`   | `B`  | `∅`  |
| `B`    | `B`  | `S2` |
| `S2`   | `S2` | `B`  |
| `∅`    | `∅`  | `∅`  |

Estado final: `S2`.

### 1. Separar finais de não finais

Começas sempre por aqui:

```text
F = {S2}

N = {S0, B, ∅}
```

Resultado:

```text
{S0}   {B}   {S2}   {∅}
```

Já estão todos separados, portanto **não há estados para juntar**.

✅ O teu AFD já é mínimo e continua com os 4 estados:

```text
S0, B, S2, ∅
```
