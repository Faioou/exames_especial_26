Um **cluster de computação** é um conjunto de **vários computadores separados** que estão ligados por uma **rede** e trabalham em conjunto.

Pense assim:

```text
Computador 1 ─┐
Computador 2 ─┼── rede ── trabalham juntos
Computador 3 ─┘
```

Cada computador pode ter:

* 1 processador ou vários;
* 1 core ou vários cores;
* a sua própria memória RAM.

O importante é: **são computadores diferentes ligados por uma rede**.

### Exemplo simples

Imagine que tem um trabalho enorme para fazer.

Em vez de um único computador fazer tudo:

```text
1 computador
↓
faz 100% do trabalho
```

num cluster:

```text
Computador A → faz uma parte
Computador B → faz outra parte
Computador C → faz outra parte
```

Assim podem terminar mais depressa.

### Não confunda cluster com multicore

Isto é importante.

**Multicore:**

```text
1 computador
└── 1 CPU
    ├── core 1
    ├── core 2
    ├── core 3
    └── core 4
```

É **um único computador**.

**Cluster:**

```text
Computador 1
Computador 2
Computador 3
Computador 4
      ↓
ligados por rede
```

São **vários computadores**.

Nos PDFs que enviou encontrei explicações sobre multicore, por exemplo vários cores dentro do mesmo sistema a partilharem memória principal, mas **não encontrei uma definição explícita de cluster** nesses PDFs. 

### Então qual é a resposta do exercício?

A correta é:

**b) É um sistema em que os computadores (com um ou mais processadores/cores) estão ligados através de uma rede local de alto desempenho.**

Porque um cluster é isso mesmo:

> **vários computadores + rede + trabalho conjunto**

As outras estão erradas porque:

* **a)** fala em vários processadores ligados por um barramento — isso descreve mais uma máquina multiprocessador, não um cluster.
* **c)** diz que os computadores têm de ser de baixo desempenho, ter só um processador/core e usar rede sem fios — nada disso é requisito.
* **d)** fala em vários cores de um único processador — isso é multicore, não cluster.

A frase para decorar é:

> **Cluster = vários computadores independentes ligados por uma rede para trabalharem em conjunto.**
